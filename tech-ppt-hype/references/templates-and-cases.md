# 叙事框架、句式模板与改写案例

以下模板用于组织表达。`[方括号]` 是待填信息，不是已验证事实；缺少材料时删除该项、改写为定性句，或在交付正文之外列待补信息。案例为构造示例，不能作为用户项目结果。

## 一、四种叙事框架

### 1. 痛点锁扣：问题与能力一一对应

结构：具体场景问题 → 现有流程限制 → 已实现机制 → 对应价值。

> 原始事实：能检测人员，判断是否进入指定区域，并记录触发图像。
>
> 包装版：面向作业区域越界风险，联动人员识别与区域关系判断，将检测结果转化为可定位、可复核的越界事件。

“行业长期受制于进口”“攻克瓶颈”“原创技术”分别需要行业、验证或创新依据，不能作为开场固定前缀。

### 2. 对比举证：先给参照，再给变化

结构：对比对象与条件 → 可比指标或机制差异 → 适用范围。

> 有数据：在 `[数据集/硬件/测试条件]` 下，`[指标]` 从 `[基线结果]` 变为 `[本方案结果]`。
>
> 无性能数据但有实现：采用跟踪与时序证据，将单帧识别扩展为多帧持续确认，并输出触发帧供复核。

机制差异可以直接陈述；误报降低、精度提升和“技术代差”需要实际对比。不能只列知名企业名字证明第一梯队。

### 3. 价值翻译：技术输出连接业务用途

结构：技术机制 → 工作流变化 → 已验证价值或待验证收益。

> 原始事实：保存异常图片、位置与时间。
>
> 包装版：围绕异常事件形成图像、位置和时间证据，支持现场复核与后续处置追踪。

省时、省钱、替代人工与进口替代均需额外证据。合理预期写“有望减少……，后续通过……验证”，不要自动从技术指标换算经济收益。

### 4. 趋势叙事：发展方向落到当前动作

结构：有依据的趋势或明确的判断 → 目标场景 → 当前能力 → 下一步目标。

> 面向巡检由单点检测向任务协同发展的需求，项目以感知、定位与事件证据为基础，逐步推进可复用的巡检能力建设。

发布会可增强节奏：“看见异常、定位风险、留存证据——让感知结果进入处置流程。”前提是各动作实际存在。市场规模、行业拐点和领先位置须另有来源。

## 二、按页面用途选句式

| 页面 | 句式 | 使用条件 |
|---|---|---|
| 开篇 | “围绕 `[场景问题]`，构建 `[核心能力]`，支撑 `[业务用途]`。” | 能力与用途可对应 |
| 技术亮点 | “融合 `[信息源]` 与 `[机制]`，把 `[原始输出]` 转化为 `[可用结果]`。” | 只填实际信息源与机制 |
| 量化结果 | “在 `[条件]` 下，完成 `[样本数]` 次测试，成功 `[次数]`、失败 `[次数]`。” | 样本与失败不省略；不得外推未测场景 |
| 团队贡献 | “本人负责 `[模块/决策]`，团队完成 `[集成/验证]`。” | 区分个人与团队，第三方基础按事实归属 |
| 合作进展 | “已与 `[对象]` 开展 `[洽谈/试用/签约/交付]`。” | 洽谈、意向、签约、交付和收款不可互换 |
| 下一步 | “下一阶段拟围绕 `[问题]` 开展 `[验证/研发]`，以 `[判据]` 评估成效。” | 目标保留将来状态 |

## 三、宣传文案的构造案例

以下为自拟案例，保留技术宣传的表达方法，不引用未注明出处的政府媒体文章，也不继承其数字与能力断言。

假设事实：原型已实现多设备状态接入、任务下发与结果归档；仅在演示环境跑通，有人工处理异常，尚未完成现场长期验证。

| 用途 | 包装文案 | 锚点与边界 |
|---|---|---|
| 标题 | “统一调度，多端协同” | 对应状态接入与任务下发；不写全自主 |
| 技术页 | “贯通设备状态、任务指令与结果记录，形成可追踪的协同任务链。” | 对应已实现的三类数据 |
| 演示页 | “在演示环境完成任务下发与结果归档，异常环节由人员接管。” | 演示状态与人工介入均保留 |
| 规划页 | “下一步面向实际作业环境验证任务恢复与连续运行能力。” | 不写成已具备现场可靠性 |

组织整段时，可用“场景开场 → 机制亮点 → 现有证据 → 发展目标”。用户只要一个标题或短句时，不强制扩成四段。

## 四、交付前核对

1. **新增事实**：数字、量级、排行榜、合作与市场规模均有依据；构造案例不可迁移到用户项目。
2. **指标口径**：保留单位、分母、条件与日期；百分比、百分点、倍数分别计算。Token、算力、参数量和效果不直接互相替代。
3. **状态**：已实现功能、已测结果、当前进展、计划目标、待确认分别表达。台架或实验室验证不能写成现场验证，演示不能直接证明商业落地。
4. **能力范围**：自研、端到端、闭环、全自动与零干预均有具体范围；第三方能力不能归为本人或团队原创。
5. **领先性**：限定场景、使用“据我们所知”或改成“第一梯队”仍需依据。不要把换词当作已经完成法律合规判断。
6. **听众与火力**：技术评委看机制与证据，领导看价值与决策，投资人看客户假设与发展空间。提高火力不省略事实限定；阶段成果按真实状态可以展示。
