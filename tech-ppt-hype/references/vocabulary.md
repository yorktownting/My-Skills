# 技术包装七层词库

用具体事实搭骨架，再用意象与修辞增加气势。词库提供表达选择与使用条件；选词不能改变原始功能、规模、验证状态或贡献归属。

## 第一层：定调词

| 词或短语 | 适用条件 | 表达示例 |
|---|---|---|
| 技术底座、统一表征 | 实际支持多个模块或任务的共同接口、数据或能力 | “以统一空间表征连接感知、定位与任务规划。” |
| 全局研判、体系能力 | 实际整合多个因素或模块，说明整合范围 | “把单点识别扩展为空间关系与时序证据联合研判。” |
| 前沿探索、新赛道 | 表达研究方向或布局，不充当成果结论 | “面向基础设施自主巡检开展前沿探索。” |
| 战略抓手、能力积累 | 能说明与业务目标或长期资产的关系 | “以现场巡检为切入点，积累可复用的感知与定位能力。” |
| 行业共识、范式转变 | 需要公开依据或明确作为观点 | “我们判断，跨任务复用将成为后续研发的重要方向。” |

## 第二层：能力包装词

| 原始事实 | 可用措辞 | 使用条件与边界 |
|---|---|---|
| 自己写了业务代码 | 自主开发、自研业务模块 | 写明自研范围与第三方基础；不能直接升级为完全自主可控 |
| 完成前端与后端 | 全栈开发、前后端一体化 | “端到端模型”有特定技术含义，不能当作前后端开发的同义词 |
| 多个功能共享流程或数据 | 一体化平台、统一入口 | 功能多但互相独立时，不写统一底座或一体化 |
| 模块之间交换数据 | 协同处理、模块联动 | 有反馈、处置与复核链路才写闭环；“无缝”需实际使用依据 |
| 限定步骤无需人工 | 自动处理、指定环节自主执行 | 标明自动化范围、人工接管与前置条件；不能扩大为全程零干预 |
| 团队会持续更新 | 持续迭代、经验沉淀 | 有明确自动学习、更新与验证机制才讨论自进化 |
| 已适配多个场景 | 可复用、模块化、可编排 | 说明已经复用的对象；拟适配场景写成目标 |

## 第三层：技术差异与领先性

- **无排名也能写强**：从单帧判断到多帧持续确认；从目标识别到空间风险研判；从告警提示到证据留存。必须符合实际实现，可突出机制差异而不虚构优越性。
- **性能对比**：同数据、同设备、同任务条件下，对照 `[基线]` 的 `[指标]` 由 `[A]` 变为 `[B]`。来源和测试条件应可追溯。
- **第一梯队、全球前十、领先**：需要具体榜单或充分的可比结果，并保留日期、项目与排名范围。同一展会或使用同类模型不构成“同台竞技”的性能证据。
- **自主可控、技术壁垒、打破垄断**：分别需要依赖与控制范围、难以替代的能力依据、市场与替代证据。不要把文化名称或自写代码用作证明。
- **率先、首次**：需要检索或对比依据；“据我们所知”与限定场景不能弥补缺少依据。

## 第四层：量化表达

| 想表达的内容 | 有依据时的写法 | 没有数据时的方向 |
|---|---|---|
| 覆盖范围 | `[对象/分母]` 中覆盖 `[数量/比例]` | 写明支持的对象、环节和适用范围 |
| 处理速度 | 在 `[硬件/输入/负载]` 下测得 `[时延/吞吐]` | 说明减少了哪些处理或人工步骤 |
| 指标提升 | 从 `[A]` 到 `[B]`，注明单位与口径 | 写机制变化或计划验证的指标 |
| 稳定性 | `[时段/样本数]` 下的成功数、失败数或可用性 | 写实际具备的容错、异常状态或接管机制 |
| 数据与业务规模 | 统计期内的真实数量，区分累计与活跃 | 用场景和能力范围，不编造“亿级、万亿级” |

**百分比、百分点与倍数不可互换。** 例如假设准确率从 80% 到 90%，增加 10 个百分点，相对增加 12.5%；不能写“提升 10 倍”。倍数优先写“达到原来的多少倍”，说明分母。此处数字仅演示计算口径。

做锚点换算时保持单位与统计口径一致，并写出换算前提。Token 数不能直接等同于算力，参数规模不能直接等同于效果，演示次数不能直接等同于现场可靠性。估算保留“按……假设估算”，研发目标保留“拟达到”。

## 第五层：趋势与价值

- 阶段叙事：从单点工具向任务协同发展、从识别结果向处置流程延伸。优先描述本项目实际变化。
- 布局叙事：面向新场景提前积累能力、构建可复用模块、形成后续验证基础。
- 市场叙事：有来源时写规模、年份、地区与口径；没有来源时写目标客户和需求假设。
- 使命叙事：服务生产安全、提高巡检覆盖、支撑产业升级。已实现收益、潜在价值与未来目标分别表达。

“窗口期、超级蓝海、产业拐点”可作为有依据的判断或明确的观点，不把宏大叙事写成确定预测。

## 第六层：气势动词

构建、贯通、统筹、凝练、锚定、拓展、沉淀、协同、重构、驱动、突破、激活。将动作落到具体对象：“贯通感知与定位数据”“沉淀跨场景复用能力”。

“打破垄断、重塑格局、重新定义、行业领跑”额外涉及市场或领先性主张，须符合第三层条件。用户明确需要宣传修辞时，可加强节奏与画面感，不以更强动词补事实缺口。

## 第七层：互联网黑话

| 黑话 | 具体含义 | 用法 |
|---|---|---|
| 抓手 | 切入点 | “以巡检任务为抓手，组织感知与定位研发。” |
| 闭环 | 输入、处理、反馈与复核链路 | 列出实际环节，缺少反馈时用“流程” |
| 赋能 | 提供能力 | 说明给谁提供什么能力 |
| 拉通、对齐 | 统一接口或口径 | 写清被统一的数据、目标或职责 |
| 沉淀、复盘 | 可复用资产与经验总结 | 写清代码、数据、规范或机制产物 |
| 飞轮 | 相互促进的循环机制 | 说明各环节与验证状态，避免当作增长保证 |
| 护城河 | 难以复制的业务或技术优势 | 需要资产、成本、数据或维护能力依据 |

用户要黑话时适度使用，一段优先不超过 2—3 个；面向非技术听众时把关键能力说清楚。
